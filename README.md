# pcba-web-datos

Datos públicos que lee la web https://passioncultureba.com (`/football` y `/trails`).

Los archivos los escribe el agente **Marcos Galperin** con su script de validación. No se editan a mano.

- `partidos.json`: partidos publicados en `/football`.
- `recorridos.json`: salidas publicadas en `/trails`, por museo.

Para deshacer una publicación: `git revert` del último commit.
